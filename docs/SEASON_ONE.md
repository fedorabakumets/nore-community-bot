# Багровый Страж Норы — сезон 1

Бесплатный розыгрыш одной физической игрушки Buffy Crochet в каталоге Mini App.
Оригинальное фото того же ракурса получено из публичного канала автора
https://t.me/buffy_crochet; локальный JPEG сохраняет кадр и авторскую отметку.
Карточка показывает весь кадр через object-fit:contain, без генерации или ретуши.

Сезонный предмет — отдельный тип карточки, не платный SKU. Нет списаний,
скидок, подарков или автоматической выдачи игровых эффектов. Заявки и итоги
хранятся в отдельных additive SQLite-таблицах. Один user_id — одна запись.
Доступ Mini App и проверка полного профиля сохранены. Публичный список чужих
профилей не выдаётся; список участников доступен только сотруднику с
admin.panel И contest.cookies. Это существующее право конкурса, по умолчанию владельцу.

Каталог → карточка → «Управление розыгрышем» → участники → «Подвести итоги…».
Тот же механизм доступен в Админ-панели → Конкурс → Сезон 1 · Багровый Страж Норы.
Подтверждение действует 5 минут и привязано к администратору и точному составу
участников. При новой заявке нужно заново подтвердить актуальное количество.
После подтверждения secrets.randbelow выбирает один индекс равновероятно.
Под блокировкой BEGIN IMMEDIATE сохраняются победитель, время, организатор,
число участников, SHA256 упорядоченного списка ID и уведомление победителю.
Ни клиент, ни организатор не передают ID победителя. Повторный выбор запрещён.

Заявки открыты с публикации. Дата итогов не задана владельцем; интерфейс честно
указывает, что её объявят отдельно. Автоматического выбора, публикации в чат
или сбора адресов нет. Получение физической игрушки организуется командой Норы.
Тесты и браузер используют только fake-пользователей и временную SQLite.
