# Проморолик Mini App NORA

`nora-miniapp-tiktok-10s.mp4` — вертикальный ролик 1080×1920, 30 кадров/с,
10 секунд. В нём показаны сообщество, игры, события, профиль и магазин.
Карточки интерфейса иллюстративные, персональных данных и production-съёмки нет.
Звуковая дорожка синтезирована в `render_tiktok.py` из простых тонов и ударных;
сторонняя музыка не используется.

Для повторной сборки нужны Pillow и imageio-ffmpeg:

```sh
python promo/render_tiktok.py
```

Перед публикацией в TikTok проверить актуальные требования площадки и
доступность Mini App для целевой аудитории: на момент подготовки доступ
ограничен ролями admin и owner.
