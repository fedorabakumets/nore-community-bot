# Первая Mini App Норы

Кабинет, каталог, текущее мероприятие и история кошелька открываются через
кнопку «Открыть Нору» в личном диалоге. HTTPS: Railway domain сервиса бота,
порт8080. Отдельного poller, копии балансов или новой схемы базы нет.

HTTP aiohttp работает в том же asyncio-процессе, что и long polling.
MINIAPP_ENABLED=1 включает сервер; MINIAPP_URL включает кнопку меню Telegram.
PORT задаёт порт; отключение HTTP возможно отдельным env-флагом без удаления данных.
Статика находится в community_bot/web. Вне Telegram показывается явно отмеченная
демонстрация с вымышленными данными и отключёнными покупками.

Каждый /api запрос требует Telegram initData в Authorization:tma. HMAC-SHA256
проверяется на сервере по bot token, сравнение constant-time, TTL1час, будущая
дата ограничена30секундами, повторяющиеся поля запрещены. user_id никогда не
берётся из JSON/URL клиента. Ни token, ни Telegram initData не записываются
в браузерное хранилище, файлы или access logs. Ответы API no-store, CORS не включён.
Поля профиля возвращаются по разрешённому списку, без модераторских заметок.

Цены и скидки берутся из общей функции магазина. Подготовка покупки создаёт
существующий wallet_intent; списание происходит только после подтверждения,
с проверкой владельца, версии каталога, срока и однократного использования.
В первой версии прямо в Mini App доступны щит, иммунитет и приватный профиль.
Товары с дополнительными шагами, подарки, питомцы и ручные платежи остаются
в боте. Каталог показывает их без обещания прямой выдачи.

Событие выбирается общей current_event. Сервер заново проверяет ID/цену;
оплата использует pay_event_offer, бесплатная запись — add_rsvp. Дубли защищены
общим ключом event/user. Залог учитывается существующей экономикой.
Транзакции и баланс общие с ботом. Из приложения нельзя назначать роли,
начислять печеньки или просматривать чужие профили/журналы.

Проверки: тестовые HMAC/TTL, подмена получателя/цены, повтор подтверждения,
реальный локальный HTTP401 для неподписанных вызовов, мобильные4экрана и
модальное подтверждение в Chromium. Реальную initData конкретного человека
можно получить только при его собственном открытии Mini App в Telegram;
тестовые подписи не используются в production.
