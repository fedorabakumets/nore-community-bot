# Нора — Telegram community bot

Один Python-процесс обслуживает личные чаты и группу: анкеты, тикеты,
профили, кабинет, модерацию, печеньки, магазин, игры и питомцев.
Кабинет доступен внутри Telegram-бота и в Telegram Mini App.
Новички подают анкету и проверяют её статус в Mini App. После одобрения открываются
профиль и уведомления. Заполненный профиль даёт доступ к Комьюнити, интерактиву,
друзьям, магазину, мероприятиям и кошельку. Админ-панель учитывает права роли.
См. [Mini App](docs/MINIAPP.md).

## Ветки и безопасные проверки

`main` содержит старую версию. Railway production автоматически развёртывает
`cursor/nora-2-update-d133`; её HEAD совпал с production SHA при проверке.
Не отправляйте изменения в эту ветку без разрешения на публикацию.

Python >=3.11 (в среде разработки 3.12):

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python tools/check_local.py
.venv/bin/python -m pip check
```

`check_local.py` запускает Ruff и pytest, блокируя сетевые подключения Python
при выполнении tests. Тесты используют временную SQLite и fake Bot.
Не помещайте production секреты и рабочую базу в эту копию.
На исходном commit: 148 tests passed, Ruff без замечаний, pip check успешен.

## Настройки и запуск

Настройки перечислены в `.env.example` и `community_bot/config.py`.
Для интеграционной проверки нужны отдельные тестовые бот, чат и SQLite.
Обязательны BOT_TOKEN и ненулевой OWNER_ID. OWNER_IDS дополняет OWNER_ID;
`COMMUNITY_CHAT_ID` имеет приоритет перед `GROUP_ID` и задаёт единственную группу,
из которой Нора принимает события. Без этого ID работают личные чаты и Mini App.
Для бонуса за подписку задайте `FREEBIE_CHANNEL_ID` и `FREEBIE_CHANNEL_URL`.
Секреты храните вне Git.

До запуска настройте COMMUNITY_INVITE_URL. Для покупки печенек бот и Mini App
используют ссылку Ozon Банка из `community_bot/config.py`. QR-код для сообщения
бота хранится в `assets/payments/nora-sbp.jpg`, для Mini App — в
`assets/payments/ozon-sbp.jpg`. При смене получателя обновляйте ссылку и оба изображения.

```sh
# Только после настройки отдельного тестового окружения:
.venv/bin/python -m community_bot.main
```

Запуск main меняет SQLite, команды Telegram, webhook и может публиковать
объявления и Telegraph. Не используйте main как healthcheck. Не запускайте
второй poller с production BOT_TOKEN.

### Нора ИИ, память чата и обновления

Нора использует DeepSeek с `DEEPSEEK_API_KEY` или OpenRouter с
`OPENROUTER_API_KEY`. По умолчанию для OpenRouter используется `openrouter/free`.
Ключи задаются в секретах среды. Команды и встроенные сценарии имеют приоритет.

Нора ИИ доступна со 2-го уровня питомца в личке и в основном чате
(`COMMUNITY_CHAT_ID` или `GROUP_ID`). В основном чате можно спросить, что обсуждали
за последние 48 часов. Модель получает подходящие фрагменты сохранённого текста
и подписей к медиа. Справка о функциях и журнал публичных обновлений доступны ИИ
в обоих режимах. Даты в журнале указывают появление записи в ветке выпуска.
Скачивание коротких видео по ссылке открывается с 3-го уровня питомца.

Личные дневные лимиты общие для чата и лички. Бронза — 5, серебро — 10, золото —
100 запросов. Счётчик сохраняется при перезапуске и сбрасывается в полночь по
часовому поясу сообщества. Одно обращение считается одним запросом, даже если
модель дважды вызывается для поиска и ответа. Ошибка провайдера тоже учитывается.

Во время похода питомца ИИ и видеозагрузки для его владельца приостановлены.
Кнопка «Вернуть из похода» есть в карточке питомца в боте и Mini App. Досрочный
возврат завершает поход без награды. Характеристики, списанные на старте, не восстанавливаются.

## Данные и контейнер

SQLite создаётся по DATABASE_PATH. В Railway том nora-data смонтирован в
/app/data; фактическое production значение DATABASE_PATH не извлекалось.
Dockerfile не копирует базу из репозитория. В проверенном Git-дереве базы нет,
хотя прежний README обещал вложенную копию. При пустом томе приложение создаёт
новую базу; это не перенос пользователей, ролей и балансов.

Изменения production, deploy, миграции, backup/restore и перенос аккаунтов
требуют отдельного согласования. Диагностика production не изменяла.
