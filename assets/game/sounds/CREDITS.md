# Звуки игры NORA

Все файлы ниже используются на условиях CC0 1.0 и преобразованы из OGG в MP3.

- `footstep_grass_*`, `footstep_wood_*`: Kenney, Impact Sounds — https://kenney.nl/assets/impact-sounds (копия: https://github.com/Mcamento8/open-game-sfx-index).
- `doorOpen_1`, `doorClose_1`: Kenney, RPG Audio — https://kenney.nl/assets/rpg-audio (копия: https://github.com/Mcamento8/open-game-sfx-index).
- `birds_dawn`: resaural — https://freesound.org/people/resaural/sounds/634511/.
- `crickets`: felixblume — https://freesound.org/people/felixblume/sounds/479041/.
  Оба звука природы взяты из переработанных циклов https://github.com/euuuuuuan/todak-public/blob/main/CREDITS.md.
