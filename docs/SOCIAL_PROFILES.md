# Профили, друзья и активность

В ЛК → Друзья имя/аватар открывают профиль. Точный @username или ID можно
ввести в поле поиска и нажать «Открыть профиль». Отображаются имя, фото,
описание, возраст, увлечения, репутация, уровень и заполненность. Баланс,
долги, модераторские заметки, file_id и токены в публичный профиль не входят.
Скрытие профиля проверяется прежней can_view_profile на сервере: дружба сама
по себе не обходит закрытый профиль. Старое право просмотра закрытых профилей
сохраняется для сотрудников, которым оно назначено. Блокировка в любую сторону
закрывает обычный просмотр профиля и аватара, включая прямые API-запросы.

«В сети в Норе» означает открытое видимое окно Mini App. Бот не читает статус
человека во всём Telegram. Сеанс отправляет heartbeat раз в 20 секунд, сервер
считает его онлайн не дольше 60 секунд без обновления. При скрытии/закрытии
окна отправляется offline; если WebView не успел отправить его, срабатывает TTL.
Учитываются отдельные сеансы: закрытие одной вкладки не выключает другую.
Порядковый номер не даёт запоздалому запросу воскресить закрытый сеанс.
У каждого пользователя не более пяти записей сеансов, время задаёт сервер.
Активность показывается друзьям; у закрытого профиля скрывается автоматически.
В ЛК есть отдельная настройка «Видимость активности». При скрытии статус и
время последнего визита не выдаются. Это не отключает доступ к самой Норе.

Кошелёк → Перевести предлагает список друзей и прежний ручной ввод ника/ID.
Можно начать перевод непосредственно из списка друзей или посещаемого профиля.
Получатель и комиссия показываются до подтверждения. Подтверждение привязано
к отправителю, получателю и сумме, использует общий ledger. Дружба повторно
проверяется внутри транзакции списания; удалённый/заблокированный друг не может
получить перевод по старому подтверждению. Прежние ручные переводы сохраняются.

Новые API: GET/POST /api/presence, GET /api/people?recipient=точное_имя,
GET /api/people/{id}, GET /api/people/{id}/avatar. Все защищены Telegram initData
и прежним ограничением Mini App по рангу. Новые таблицы только для активности
и её приватности; профиль, фото и балансы общие с ботом.

## Кнопка запуска Telegram

Персональная кнопка «Открыть Нору» уже устанавливается через setChatMenuButton
допущенным пользователям; у остальных меню команд. Это кнопка внутри диалога.
Строка в списке чатов управляется клиентом Telegram, Bot API не позволяет
рисовать там кнопки или выборочно показывать Main Mini App по внутренним ролям.

Для системного запуска владелец бота должен в @BotFather открыть /mybots →
@nora_community_bot → Bot Settings → Configure Mini App и включить Main Mini App,
указав https://nora-bot-production-2126.up.railway.app/.
Кнопка Main Mini App общая, её отображение зависит от клиента Telegram;
допуск по роли на сервере остаётся обязательным. Не нужен новый бот или токен.
Аккаунт владельца BotFather в этой рабочей среде не подключён; доступ к GitHub
и Railway не даёт права управлять BotFather. Публичная страница бота при проверке
показывала Start Bot, а не Open App. Настройка Main Mini App не изменялась.

Официальная документация: https://core.telegram.org/bots/webapps#launching-the-main-mini-app
и https://core.telegram.org/bots/webapps#launching-mini-apps-from-the-menu-button.
