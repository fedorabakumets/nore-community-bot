# Новый стиль меню Норы

Стандартные меню, пять видов питомцев, приветствие и обложки обновлений
используют 38 карточек из community_bot/menu_art.py. Иллюстрации созданы image_gen
по предоставленному владельцем референсу бабушки: платок, кудри, круглые очки.
В каждой сцене есть контекст раздела и небольшой ироничный акцент.

## Общая сетка

- Размер: 768×512, соотношение 3:2.
- Шрифт: Monocraft, одинаковый для кириллицы, латиницы и цифр. Лицензия OFL
  приложена в assets/fonts/Monocraft-LICENSE.txt; источник IdreesInc/Monocraft.
- Основной заголовок: 40 px, белый; координаты 48,244, межстрочный шаг 56 px.
- Бренд NORA: 20 px, красный #ef233c, координаты 48,40.
- Красный штрих: 48,212–116,215. Номер обновления: тот же шрифт 20 px.
- Размер заголовка не уменьшается автоматически: длинные названия размещены
  в две строки в той же сетке. Растеризация букв без сглаживания сохраняет
  пиксельный рисунок шрифта.
- Палитра рисунка: чёрный, белый, нейтральные серые для размытия, красный акцент.
  Бабушка и предметы мягко размыты в генерации; текст набирается резко поверх.

## Исходники и отправка

10 WebP-атласов в assets/art/grandma содержат по четыре сцены без текста.
Координаты плиток и подписи зафиксированы в COVERS. Последние две плитки — запас
для будущих разделов, сейчас в интерфейсе не используются. Генерируемые файлы
assets/menu-covers/grandma-v1 исключены из Git: их создаёт общий рендерер.

Docker выполняет python -m community_bot.menu_art при сборке. Если отсутствует
атлас, шрифт или заголовок не укладывается в сетку, сборка останавливается.
При разработке те же файлы создаются по запросу и переиспользуются по времени
изменения исходников. Заголовки не поручаются генератору картинок: один шрифт,
одни размеры и координаты применяются ко всему комплекту.

blocks.cover_path выбирает новую обложку для всех 31 существующих блоков.
Питомцы используют собственную новую сцену, сохраняя выбранный вид животного.
Приветствие выбирает новую комплектную обложку. Анонсы и иллюстрации новой
страницы Telegraph используют тот же стиль. Полное название выпуска остаётся
в подписи сообщения, на картинке — единый заголовок и номер.

Старые уже отправленные сообщения не редактируются массово. Новые обложки
появляются при открытии/обновлении меню. Пользовательские фото профилей,
чеки, вложения и фотографии утренней сводки не относятся к этому комплекту.
Схема данных, балансы, кнопки и игровые правила этим обновлением не меняются.
