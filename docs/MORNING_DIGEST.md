# Утренний закреп: обновление

Фотографии assets/morning сохранены без изменений. Публикация остаётся одним
сообщением с фото и подписью; без фото используется обычный текст.
Новости и история используют нативный HTML `<blockquote expandable>`.
Весь текст, включая скрытую часть, учитывается в лимите подписи Telegram.

## Новости

Публичные RSS Фонтанки, 47news и ТАСС проверены отдельно перед подключением.
Рабочий endpoint 47news — /rss/, не /rss.xml. Сбой одной ленты не мешает другим.
Каждая выбранная новость имеет дату с часовым поясом и HTTP(S)-ссылку.
Окно: от now−24h до now, будущие публикации исключаются.

Приоритет: Петербург → Ленобласть → остальные подтверждённые российские темы.
Используется лучший доступный географический уровень; одна местная новость
не дополняется федеральной только ради второго места. Максимум две.
География определяется по названию/описанию/категориям, не по адресу редакции.
Одинаковые URL и близкие по смысловым словам заголовки объединяются.
Полезные городские изменения имеют приоритет над обычной погодной заметкой.
Очевидные архивные перепечатки, гороскопы и бытовые драки исключаются.

Это детерминированные правила, не редактор с пониманием всех событий:
перефразированные дубли или двусмысленная география могут потребовать уточнения правил.
Заголовок и короткий фрагмент RSS сопровождаются ссылкой на публикацию.
Сбой всех источников отличается от отсутствия подходящих новостей.

## Именно этот день в Петербурге

Старый список из 20 случайно чередовавшихся фактов удалён.
День/месяц берутся по Москве, а возраст события считается по текущему году.
Редакторские записи привязаны к точной дате и первоисточнику; на 26 октября
проверена премьера «Золотого века» (1930) по архивной публикации Мариинского,
на 27 октября — первая Вики-конференция (2007) по итоговому пресс-релизу.
Их объяснения последствий написаны по указанным источникам.

Для остальных дат используется дневная лента Wikimedia OnThisDay: только события,
где Петербург/Петроград/Ленинград явно указан в описании. Общая российская
история не подставляется вместо городской. Ссылка на год или на город целиком
не используется как контекст события. Если есть подходящая тематическая статья,
в цитате показывается её краткий контекст с источником.

Покрытие 365 дней редакторскими карточками пока не заявляется. Лента может
не содержать подходящего события/контекста или быть недоступна. Тогда пост
честно сообщает об отсутствии подтверждения; событие соседней даты и
придуманная причинно-следственная связь не подставляются.
Редакторские карточки с источниками можно постепенно расширять в VERIFIED_EVENTS.
Если история уже опубликована утром, повторный дневной пост с историей пропускается.

## Достоверность и закрепление

Неизвестный статус метро не заменяется фиксированным перечнем станций.
Проверка TLS не отключается. HTTP-клиенты учитывают заданный окружением proxy.
Подпись сокращается до экранирования/разметки по блокам и проверяется в UTF-16;
готовый HTML не режется и данные brief не изменяются.

Сначала отправляется новый пост и закрепляется; только затем снимается старый
утренний закреп. При ошибке pin старый остаётся. pending ID хранится в bot_state:
повторная попытка не отправляет дубликат. Схема БД не меняется.
Если на дату выпуска уже опубликован старый утренний пост и его ID известен,
при первом запуске новой версии обновляется только его подпись — без новой
фотографии, сообщения или смены закрепа. Ошибка редактирования не снимает старый
закреп и не отмечает переход как успешный.

## Предпросмотр и проверки

```sh
.venv/bin/python tools/check_local.py
.venv/bin/python tools/preview_morning.py --output /workspace/nora-morning-preview.html
```

Preview читает только публичные источники, не запускает main, не использует BOT_TOKEN
и не отправляет сообщений. HTML-макет приблизительно показывает раскрытие;
окончательный вид зависит от Telegram-клиента.
После выпуска проверить в логах обновление текущей подписи. Если сегодняшнего
поста нет, расписание остаётся прежним; отдельный пробный пост можно отправить
существующей кнопкой утренней сводки в панели администратора.
