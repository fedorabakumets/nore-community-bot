# NORA — Liquid Motion

Вертикальный motion-ролик из шести предоставленных владельцем скриншотов реального
интерфейса. Формат: 1080 × 1920, 60 fps, 20 секунд, H.264 / AAC, fast start.
Стеклянное обрамление, перспективные пролёты, инерционная прокрутка, фиксированная
навигация, подсветка нажатий и раскрытие рейтинга — монтажная анимация скриншотов.
Бот и production Mini App для съёмки не запускаются.

Музыка: предоставленный `Serato Recording 397.mp3`, фрагмент **20,74–40,74 с**.
Сильный удар около **24,74 с** исходника совпадает с **4,00 с** ролика.
Дальше основные разделы сменяются через шесть долей монтажной сетки 155 BPM.
Громкость снижена для запаса по пикам; короткие фейды на входе и выходе.

## Монтаж

- 0,00–4,00: логотип и объёмный веер экранов, разгон перед дропом.
- 4,00–6,32: главная, скролл, нажатие вкладки магазина.
- 6,32–8,65: магазин, прокрутка товара, переход в коммьюнити.
- 8,65–10,97: коммьюнити, нажатие и раскрытие настоящего рейтинга.
- 10,97–13,29: события, прокрутка карточки Нового года.
- 13,29–15,61: реальный профиль владельца.
- 15,61–17,94: пять разделов собираются в объёмную композицию.
- 17,94–20,00: фирменный логотип и «Свои рядом».

## Повторный рендер

Из корня репозитория, в отдельном Python 3.12 с пакетами из requirements.txt:

```powershell
python -m pip install --target .render-deps -r promo/liquid_motion/requirements.txt
python promo/liquid_motion/render.py --attachments "ПАПКА_ВЛОЖЕНИЙ" --preview
python promo/liquid_motion/render.py --attachments "ПАПКА_ВЛОЖЕНИЙ" --render
```

В папке входных материалов ожидаются один MP3 и JPG с префиксами `2-` ... `7-`.
Рендер использует шесть локальных процессов; скриншоты и музыка не загружаются
во внешние сервисы. Логотип берётся из векторных контуров `community_bot/web/intro.js`.
Итог: `NORA-Liquid-Motion-20s.mp4` рядом со скриптом. Предпросмотр: `contact-sheet.jpg`.
Исходные вложения и экспорт не включаются в Git; пути к секретам не используются.
