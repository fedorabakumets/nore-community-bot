# Nore Community Bot

Один Telegram-бот обслуживает личные чаты, группу сообщества, анкеты, тикеты, модерацию,
профили, репутацию, внутреннюю экономику, игры и тамагочи.

## Что входит в комплект

- исходный код бота;
- Dockerfile и Docker Compose для автономного запуска на VPS;
- изображения из `assets/`;
- очищенный снимок рабочей SQLite-базы `data/community.db`;
- тесты и средства проверки кода;
- шаблон настроек `.env.example` без токенов и реквизитов.

В комплекте нет данных исходного VPS, SSH-ключей, Telegram-токена, личного `OWNER_ID`,
личных сессий Telegram, платёжной ссылки или приватной ссылки на канал.

## Основные функции

- пошаговая анкета с обязательным онлайн-интервью;
- одобрение и отказ по анкетам из админ-панели;
- тикеты с текстом, фото, видео, аудио и документами;
- роли `owner`, `admin`, `moderator`, `member`;
- мут/анмут, варн/анварн, кик, бан и разбан;
- профили с аватаром/видео, именем, возрастом, увлечениями, статусом и статистикой;
- баланс 🍪, переводы с комиссией 20%, магазин и скидки 20%/10%;
- репутация с ежедневным восстановлением на 5 единиц в 00:00 МСК;
- ручные заявки на покупку печенек через СБП со скриншотом;
- автосообщения, рассылки, массовое упоминание и общий мут чата;
- антифлуд, фильтры, ночной и рейд-режим, аудит и статус системы;
- русская рулетка и три групповые игры: «Контрабанда», «Сбой протокола», «Аукцион убежища»;
- тамагочи с едой, водой, наградами за сообщения и медленным накоплением крошек;
- одноразовая награда за подписку на канал.

## Подготовка Telegram

1. Создайте нового бота через `@BotFather` или получите у продавца права на существующего бота.
2. В `@BotFather` выполните `/setprivacy` → выберите бота → `Disable`. Иначе обычные команды в группе
   не будут видны боту.
3. Добавьте бота в группу администратором с правами удалять сообщения, ограничивать и банить.
4. Владелец и модераторы должны открыть личный чат с ботом и выполнить `/start`.
5. Для проверки подписки добавьте бота администратором в нужный канал.

## Настройка

Скопируйте `.env.example` в `.env` и заполните своими данными:

```dotenv
BOT_TOKEN=
OWNER_ID=0
MODERATOR_IDS=
COMMUNITY_CHAT_ID=0
DATABASE_PATH=data/community.db
WELCOME_COVER=assets/bot-avatar.jpg
EVENT_PASS_PRICE=0
SUPPORT_PRICE=0
RESTRICTED_REPUTATION_THRESHOLD=0
TIMEZONE=Europe/Moscow
COOKIE_PRICE_RUB=10
SBP_PAYMENT_URL=
FREEBIE_CHANNEL_ID=0
FREEBIE_CHANNEL_URL=
```

- `BOT_TOKEN` — токен от `@BotFather`.
- `OWNER_ID` — Telegram ID нового владельца.
- `MODERATOR_IDS` — ID модераторов через запятую.
- `COMMUNITY_CHAT_ID` — ID группы, обычно начинается с `-100`.
- `SBP_PAYMENT_URL` — СБП-ссылка нового продавца.
- `FREEBIE_CHANNEL_ID` и `FREEBIE_CHANNEL_URL` — ID и ссылка канала для бонуса.
- `WELCOME_COVER` принимает Telegram `file_id`, URL или путь к файлу внутри контейнера.
- `RESTRICTED_REPUTATION_THRESHOLD=70` блокирует общение ниже 70; `0` ограничивает только отрицательную репутацию.

Пока `SBP_PAYMENT_URL` или `FREEBIE_CHANNEL_URL` пусты, соответствующая функция покажет понятное сообщение
о незавершённой настройке и не создаст невалидную Telegram-кнопку.

## Запуск на новом VPS

Требуется Linux VPS с Docker Engine и Docker Compose v2.

```bash
cp .env.example .env
nano .env
docker compose up -d --build
docker compose ps
docker compose logs -f --tail=100
```

При первом запуске Docker создаёт том `nore_community_bot_data` и автоматически помещает в него
переданную `data/community.db`. После этого база живёт в Docker-томе и не перезаписывается при обновлениях.

Если том с таким именем уже существует, Docker сохранит его текущее содержимое. Для импорта именно базы
из архива нужно использовать новое имя тома или вручную восстановить SQLite-файл.

## Обновление и резервная копия

```bash
docker compose up -d --build
docker run --rm -v nore_community_bot_data:/data -v "$PWD":/backup alpine \
  tar czf /backup/nore-community-data.tar.gz -C /data .
```

## Команды

В личном чате: `/start`, `/apply`, `/question`, `/profile`, `/shop`, `/buycookies`, `/close`, `/admin`.

В группе:

- `/profile` — свой профиль; ответом — профиль участника;
- `/transfer 100` ответом или `перевести 100 печенек`;
- `/mute 30m`, `/unmute`, `/warn`, `/unwarn`, `/kick`, `/ban` — ответом на сообщение;
- `/unban TELEGRAM_ID`;
- `/role member|moderator|admin` — ответом, для админов/владельца;
- `/setstatus Текст` — ответом, для админов;
- `/givecookies 100`, `/setcookies 100` — ответом, для админов/владельца;
- `/roulette` — пригласить участника в русскую рулетку;
- `/games` — лобби и правила групповых игр; `/gamecancel` — отмена партии;
- `/pet` — открыть тамагочи в личном чате;
- `/commands`, `/reputation`, `/store` — подробная справка;
- `халява` — награда за подписку;
- `/id` — ID пользователя и чата.

Аварийная команда владельца: `/nore_stop_9x4q`. После двойного подтверждения бот покидает известные чаты
и записывает в базу флаг остановки. Эта команда работает только для `OWNER_ID`.

Единицы времени для мута: `m/м`, `h/ч`, `d/д`, `w/н`.

## Важные ограничения

- Telegram требует оплачивать цифровые товары внутри Telegram через Stars (`XTR`). Ручной сценарий СБП
  может создать риск ограничения или удаления бота.
- Telegram `file_id` у старых аватаров, вложений и чеков может оказаться недоступен другому боту. Текстовые
  данные, роли, балансы, анкеты и история при этом сохраняются.
- База содержит Telegram ID и данные профилей участников. Новый владелец обязан обеспечить законное и безопасное
  хранение персональных данных.
