# Песни из Яндекс Музыки для NORA

Команды в чате сообщества и личке с ботом: «Нора песня Кино Группа крови», «песня Кино Группа крови», «Нора, песня «Группа крови»». Бот показывает до пяти результатов, автор запроса выбирает нужный трек.

Ссылки на конкретную песню теперь можно отправлять напрямую, без поиска по названию:

- `Нора https://music.yandex.ru/album/123/track/456`
- `Нора песня https://music.yandex.ru/track/456`
- `песня https://music.yandex.ru/track/456`
- `https://music.yandex.ru/track/456` (прямая ссылка в чате или личке)

Дополнительные параметры ссылки (например, `?utm_medium=copy_link`) не мешают распознаванию. Для ссылок на альбомы и плейлисты без конкретного `track` бот попросит ссылку на отдельную песню. По ссылке Нора сразу отправляет выбранное аудио; кнопки выбора не нужны. Кулдаун на успешную отправку: 5 минут на чат и пользователя. Повторная отправка загруженного трека использует сохранённый Telegram file_id.

## Авторизация на Railway

Интеграция отключена по умолчанию. Для запуска потребуется действующая авторизованная сессия Яндекс Музыки (для полного аудио обычно платная подписка).

1. Войди в Яндекс Музыку **в браузере на своём ПК**. Проверь, что полная композиция воспроизводится.
2. Локально экспортируй cookies домена .yandex.ru в файл Netscape cookies.txt (с табуляцией между полями); в нём должна присутствовать строка Session_id. Используй только проверенный локальный экспорт, не загружай cookies на чужие сайты.
3. В PowerShell создай Base64 из файла и скопируй в буфер (измени путь к файлу при необходимости):

~~~powershell
[Convert]::ToBase64String(
  [IO.File]::ReadAllBytes("$env:USERPROFILE\Downloads\cookies.txt")
) | Set-Clipboard
~~~

4. В секретных переменных окружения Railway создай YANDEX_MUSIC_COOKIES_B64 со значением из буфера. Добавь NORA_SONGS_ENABLED=1.
5. Дождись нового деплоя и проверь запрос песни, запись которой разрешено распространять. Затем повтори запрос, чтобы проверить Telegram file_id.

**Безопасность:** cookies дают доступ к авторизованной сессии Яндекса. Base64 не является шифрованием. Нельзя присылать значение в чат, коммитить в Git или записывать в документацию. При утечке отзови сессии Яндекса и создай новые.

## Технические ограничения

- Поиск: неофициальный https://api.music.yandex.ru/search.
- Загрузка: yt-dlp + yt-dlp-yandex-music; cookie-файл создаётся только во временном каталоге, удаляемом после запроса.
- Проверка: mutagen отбрасывает MP3, который существенно короче известной длительности (обычно превью 13–30 секунд).
- Максимальный размер файла 48 МиБ, конвертации FLAC пока нет. Неизвестные форматы не отправляются.
- Временные файлы удаляются, Telegram file_id кэшируется в базе; поток Telegram polling не блокируется во время загрузки.
- Игровые пластинки и музыкальные события NORA не меняются.
- Плагин и поиск используют **неофициальный** интерфейс, который Яндекс может изменить. Без живой авторизованной сессии реальная работа не подтверждена.
- Подписка Яндекс Музыки не предоставляет права на публичную раздачу чужих записей. Отправку файла следует применять только при наличии прав или разрешения на распространение. В иных случаях отправляйте ссылку на Яндекс.

Локальные тесты без доступа к Яндексу:

~~~bash
python -m pip install -e '.[dev]'
pytest -q tests/test_song_requests.py
~~~
