# Чек-лист приёмки

1. Распакуйте архив на новом VPS.
2. Установите Docker Engine и Docker Compose v2.
3. Создайте `.env` из `.env.example`.
4. Укажите токен своего бота, ID нового владельца, ID группы, модераторов, свою СБП-ссылку и канал.
5. Отключите privacy mode бота в `@BotFather`.
6. Добавьте бота администратором в группу и канал.
7. Запустите `docker compose up -d --build`.
8. Проверьте `docker compose ps` и `docker compose logs --tail=100`.
9. Владелец и модераторы должны нажать `/start` в личном чате с ботом.
10. Проверьте `/id`, `/profile`, `/admin`, `/commands`, одну тестовую анкету и тестовую заявку СБП.

Секреты не нужно вписывать в код, README или Compose. Они хранятся только в `.env` на VPS с правами доступа `600`.
