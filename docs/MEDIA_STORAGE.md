# Изображения и память

Mini App кэширует обработанные аватары (полный размер и миниатюры отдельно)
и обложки мероприятий в приватном S3 bucket. Авторизация и проверка доступа
выполняются до чтения кэша; для чужого профиля доступ повторно проверяется
после загрузки. Прямые публичные ссылки на личные фото не создаются.
Telegram остаётся источником оригиналов, схема SQLite не меняется.

В production создан Railway bucket `nora-media` (sjc). В сервисе бота нужны
переменные `MEDIA_S3_ENDPOINT`, `MEDIA_S3_BUCKET`, `MEDIA_S3_REGION`,
`MEDIA_S3_ACCESS_KEY_ID`, `MEDIA_S3_SECRET_ACCESS_KEY`. Их значения задаются
ссылками на одноимённые свойства bucket, например
`MEDIA_S3_ENDPOINT=${{nora-media.ENDPOINT}}`. Ключи не копировать в Git.
Используется virtual-host addressing и AWS SigV4.

Если конфигурация отсутствует, изображения загружаются из Telegram.
При ошибке S3 включается тот же путь с паузой 60 секунд до следующей попытки.
В памяти приложения нет постоянного кэша байтов изображений; ключ объекта —
хеш file_id и вариант изображения. При изменении file_id создаётся новый ключ.
Старые производные не удаляются автоматически; при росте bucket можно очищать
префикс `images/v1/`, после чего нужные изображения восстановятся по запросу.

Загрузка/обработка изображений в этих HTTP-маршрутах сериализована на приложение.
Отмена запроса дожидается работающего декодера перед освобождением слота.
JPEG уменьшается через draft/thumbnail до EXIF-копирования и RGB-конвертации.
Pillow и S3 SDK загружаются при первом использовании; шесть игровых библиотек
загружаются при открытии игры. Aiogram необходим работающему poller постоянно.
Обработка медиа в отдельных маршрутах админки и магазина пока использует
прежние пути; общий S3-кэш охватывает аватары и обложки мероприятий.

Серверный ориентир до выпуска: за 24 часа MEMORY_USAGE_GB среднее 0,8652,
максимум 1,1768, текущий образец 1,0725. Это память контейнера целиком,
а не разбор по Python-объектам. Экономию после выпуска владелец проверяет
при сопоставимой нагрузке и времени жизни процесса.
