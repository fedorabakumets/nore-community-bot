# Стикеры Норы · выпуск 20

Набор: https://t.me/addstickers/vstickere . Команда `/stickers` или слово
«стикеры» показывает ссылку и пример настоящего стикера из набора. Набор
доступен также по кнопке анонса и ссылке в статье.

Три служебных рисунка находятся в `assets/stickers/`: update.webp («ОБНОВА»),
event.webp («ТУСА»), morning.webp («Доброе утро <3»). Это статические стикеры
512×512 с настоящим альфа-каналом и размером меньше 512 КБ. Их можно отправлять
ботом напрямую; добавление в чужой набор от имени другого владельца не нужно.
Существующий пользовательский набор автоматически не редактируется.

Порядок: анонс обновления → стикер → закрепление; пост события → стикер →
необязательный опрос; утренняя сводка → стикер → закрепление. Предпросмотры
студии не отправляют стикеры в сообщество. Старые утренние посты массово не
переотправляются; новая сцена придёт со следующей штатной сводкой.

Подтверждение доставки хранится в bot_state по виду/чату/исходному сообщению.
Повторная публикационная попытка не отправляет успешный стикер второй раз.
Неудачная отправка остаётся в очереди; штатный процесс повторяет её каждые
30 секунд, в том числе после перезапуска. Ошибка стикера не ломает основной
пост. При восстановлении после сбоя стикер может появиться позже исходного
сообщения. API Telegram не предоставляет ключ идемпотентности: авария строго
между приёмом Telegram и записью подтверждения в SQLite всё ещё может дать
повтор. От штатного автоудаления ответов группы стикеры защищены.

Схема БД не изменяется. При запуске проверяется доступность существующего
набора; в журнал выводятся его имя/количество, без file URL или токенов.
Статья выпуска и восстановление изображений №18 описаны в TELEGRAPH.md.
